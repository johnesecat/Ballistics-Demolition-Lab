# Artillery Command

A side-view artillery puzzle game for mobile browsers, built with TypeScript, Phaser 3, and Matter.js.

## Features

- **59 Unique Ammunition Types** across 6 categories (Solid, HEAT, HESH, HE, APHE, Soft)
- **Destructible Physics Structures** with material-specific damage (Wood, Brick, Concrete, Steel, Armor, Slopes)
- **Procedural Level Generation** with validated solvable layouts
- **Campaign Mode** with 3 chapters, 8 stages each
- **Touch-First Controls** optimized for iPhone 15 Safari
- **Local Save System** with versioned localStorage
- **GitHub Pages Deployment** ready

## Quick Start

### Prerequisites

- Node.js 18+
- npm 9+

## Gameplay

### Core Loop

1. **Main Menu** → Continue, Campaign, Armory, Settings
2. **Campaign** → Select Chapter → Select Stage
3. **Briefing** → View objective, shot limit, star thresholds, equipped loadout
4. **Battle** → Aim, set power, choose ARC/STRAIGHT, select ammo, fire
5. **Replay** → Watch at 0.1x–2x speed, pause/finish/skip
6. **Results** → Stars, shots used, rewards, Retry/Next/Campaign

### Controls (Touch)

- **Aim**: Drag on left side of screen
- **Power**: Drag slider on right
- **Mode**: Tap ARC/STRAIGHT buttons
- **Ammo**: Tap ◀/▶ arrows to cycle loadout
- **Fire**: Tap large FIRE button
- **Reset**: Tap RESET (top-right)
- **Menu**: Tap MENU (top-right)

### Controls (Keyboard/Mouse - Testing)

- **←/→**: Adjust aim angle
- **↑/↓**: Adjust power
- **Space**: Fire
- **M**: Toggle ARC/STRAIGHT
- **A/D**: Cycle ammunition
- **R**: Reset mission

### Firing Modes

- **ARC**: High-arcing trajectory, full gravity
- **STRAIGHT**: Low, flat trajectory, reduced gravity

### Ammunition Categories

| Category | Color | Role |
|----------|-------|------|
| Solid | Blue | Direct penetration, kinetic damage |
| HEAT | Orange | Shaped charge copper jets |
| HESH | Purple | Rear-face spalling |
| HE | Red | Explosive blast & fragmentation |
| APHE | Yellow | Penetrator + delayed internal burst |
| Soft | Copper | Flatten on impact, crush/fold steel |

### Materials & Damage

Each material reacts differently to ammunition types:

- **Wood**: Vulnerable to HE, Fragmentation, Crusher
- **Brick**: Vulnerable to HE Demolition, HESH, Obstacle Reducer
- **Concrete**: Vulnerable to Heavy AP, Foundation Breaker
- **Steel**: Vulnerable to AP, HEAT, Soft rounds, Meltdown
- **Armor**: Vulnerable to HEAT, APHE, HESH Spall
- **Slopes**: Vulnerable to Bankshot, Wedge, Cornerjet

## Building for GitHub Pages

### Automatic Deployment (GitHub Actions)

The repository includes a workflow that builds and deploys to GitHub Pages on push to `main`.

### Manual Deployment

```bash
# Build production bundle
npm run build

# Output is in ./dist
# Deploy the dist/ folder to your GitHub Pages branch
# Ensure repository settings use the correct branch/folder
```

### Base Path Configuration

The game is configured for a project subpath (`/artillery-command/`). To deploy to a different subpath:

1. Update `base` in `vite.config.ts`
2. Rebuild with `npm run build`

## Save System

Progress is saved to localStorage with versioning:

- Campaign progress (unlocked chapters/stages, stars, best shots)
- Currency & ammunition unlocks
- Current loadout (6 slots)
- Settings (volumes, camera shake, reduced effects, trajectory visibility, aim sensitivity)
- Statistics (shots fired, missions completed/failed, favorite ammo)

Save data survives browser restarts and handles corruption gracefully.

## Development Notes

### Inferred Mechanics

Some ammunition behaviors are inferred from reference descriptions where visual details were unclear. These are marked in the code with `inferred: true` in the ammo catalogue.

### Known Limitations

- Matter.js sleeping can occasionally leave debris suspended; mitigated by sleep threshold tuning
- Very high-speed projectiles may tunnel through thin walls; mitigated by swept collision in trajectory preview
- Mobile Safari memory limits may require reduced effects on older devices

### Extending the Game

- **New Ammunition**: Add to `src/ammo/ammoCatalogue.ts`, run `npm run generate:icons`
- **New Materials**: Add to `GAME_CONFIG.MATERIALS` and `StructureSystem`
- **New Objectives**: Extend `LevelGenerator.selectObjective()` and `GameScene.checkMissionStatus()`
- **New Chapters**: Increase `GAME_CONFIG.CHAPTERS` and add chapter-specific generation weights

## Troubleshooting

### "Cannot find module" errors

```bash
rm -rf node_modules package-lock.json
npm install
```

### Icons not loading

```bash
npm run generate:icons
```

### Build fails on GitHub Pages

Ensure `vite.config.ts` base path matches your repository name.

### Audio doesn't play on iOS

First touch anywhere on screen unlocks audio context (handled automatically).
